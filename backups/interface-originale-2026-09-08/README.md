# Interface originale conservée

Cette archive a été créée avant la refonte graphique, le 8 septembre 2026.
Elle comprend le dossier `client/src`, `client/index.html`, `client/package.json`
et `client/vite.config.js`, avec les prêts, négociations et tactiques déjà intégrés.

Archive : `client-avant-refonte.zip`
SHA-256 : `CB7703B7D11A88E697E093FA2CD427C63FB5AFB442FBBEA11F5F4DA6A2870C94`

## Comparer sans restaurer de fichiers

Le bouton **Interface classique** réactive immédiatement la présentation verte
originale. Le bouton **Nouvelle interface** permet de revenir à la refonte.
Le choix est mémorisé dans ce navigateur, indépendamment des parties sauvegardées.
Les feuilles de style d’origine restent présentes et ne sont pas remplacées.

## Restaurer les fichiers d’origine

Décompresser l’archive dans un dossier temporaire, puis comparer les fichiers
avant de recopier `src/` et les trois fichiers de configuration dans `client/`.
L’archive ne contient ni base de données, ni dépendances, ni fichiers musicaux.
Ne pas restaurer le code par-dessus de futurs changements fonctionnels sans
comparaison : pour un simple retour visuel, utiliser le bouton de l’interface.
